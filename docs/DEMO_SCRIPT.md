# سكريبت الفيديو (3 دقايق)

الهدف: إثبات إن الوكيل بيشوف مشكلة حقيقية، يصلحها بموديلات Meta، ويقيس النتيجة على كود حقيقي.
سجّل تشغيل حقيقي بمفاتيح Meta (مش الـ mock). الأرقام بين [ ] من نتايجك أنت — متكتبش أرقام من تشغيلة مش عملتها.

## قبل التسجيل (5 دقايق)
1. `.env` فيه `MODEL_API_KEY`، وشغّل `npm run check` واتأكد إن Spark وWonder وSAM كلهم OK.
2. جهّز مجلد الموقع اللي هتوريه (نسخة على جهازك) وشغّل مرة واحدة عشان الـ cache يسخّن، أو امسح `.cache/` لو عايز تورّي أول تشغيل كامل.
3. اعمل `npm run smoke` واتأكد إنه بيعدّي، عشان تعرف إن أي مشكلة في التسجيل مش من الكود.
4. سجّل الشاشة على 1080p، والترمينال بخط كبير، والإخراج واضح.

## 0:00–0:20 — المشكلة
افتح الموقع التجريبي (أو `out/smoke/reader-before.txt`): القارئ بيقول "link, img, button, img, textbox" — عناصر من غير أسماء.
جملة: «أكتر من ٣٠٠ مليون ناطق بالعربي، وكثير من مواقعهم مش مفهومة لقارئ الشاشة.»

## 0:20–0:45 — القياس قبل
شغّل:
```
npm run fix -- file:///path/to/site/index.html --audit --out out/demo
```
اشرح: `--audit` بيقيس بس، من غير موديلات ومن غير أي تعديل. وريّ سطر:
`WCAG violations (all): [X] -> [X]` و`screen reader, unnamed elements: [X] -> [X]` (نفس الرقم قبل وبعد، لأن مفيش تغيير).
دة خط الأساس اللي هنقيس عليه.

## 0:45–1:20 — الوكيل بيشوف
شغّل:
```
npm run fix -- file:///path/to/site/index.html --out out/demo
```
وري إن SAM 3.1 بيبص على الصفحة كلقطة شاشة ويلاقي عناصر axe مش شايفها (زر أيقونة من غير نص).
جملة: «دي الحاجات اللي الأدوات التقليدية بتفوّتها.»

## 1:20–1:55 — الفهم والنقد
افتح `out/demo/report.html` (عربي RTL):
- جدول الإصلاحات: Muse Spark كتب الوصف بالعربي، ومراجع تاني (critic) شاف الصورة ووافق أو رفض.
- عمود الثقة: أي تعديل ثقته أقل من `MIN_CONFIDENCE` رايح «مراجعة بشرية» ومتطبّقش.
جملة: «إحنا بنعترف بحدود الموديل، والحاجة اللي مش واثقين فيها بتوقف لحد ما حد يراجعها.»

## 1:55–2:25 — مش نصوص بس + الكود الحقيقي
1. وري جدول «What it fixes» في README: لوحة المفاتيح (div بقى زر)، حلقة الفوكس، `main` وskip link، عنوان الصفحة، والـ zoom.
2. شغّل نفس الأمر مع `--repo`:
```
npm run fix -- file:///path/to/site/index.html --repo /path/to/site --out out/demo-repo
```
وري سطر `source patch: [N] edits in [M] file(s) for [K] fixes, [U] unmapped -> out/demo-repo/fixes.diff`.
3. افتح `fixes.diff` وبيّن إنه diff صغير على الملفات الحقيقية. لو عايز، وري `--pr` على repo بتاعك إنت بس.

## 2:25–2:50 — الإثبات
وري نفس الأسطر بعد الإصلاح:
- `targeted classes: [X] -> 0`
- `screen reader, unnamed elements: [X] -> 0`
- `elements that moved: 0 | pixels changed: 0.000%` (أو نسبة التباين المقصودة لو فيه إصلاح ألوان).
- `reader-after.txt`: "link 'السلة', button 'بحث'..." كلام مفهوم.

## 2:50–3:00 — النتايج والحدود
وري جدول `npm run eval` على [N] موقع (ملفات `eval/results.csv`)، وبعدها الحدود بصراحة:
- التباين على النص العربي و`dir="rtl"` بيتحل جزء منهم، والباقي بيروح مراجعة بشرية.
- وضع `--repo` بيتعامل مع HTML ثابت؛ قوالب JSX/Vue بتتبعت لـ Wonder بس مش دايماً بتتحقق.
- «كل الكود اتكتب خلال فترة الهاكاثون» + لقطة `git log --date=short --pretty='%h %ad %s'`.

## قواعد أمان أثناء التسجيل
- متفتحش PR على مواقع ناس تانية. أي موقع حقيقي بيتفحص محلياً أو في نسخة من كودك.
- متوريش مفاتيح ولا `.env`. امسح أي log فيه توكن قبل الرفع.
- لو موديل رجّع اقتراح غلط، سيب المشهد زي ما هو واشرح إنه راح مراجعة بشرية — دي ميزة مش عيب.
